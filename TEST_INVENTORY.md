## Supplemental checks and speech boundaries

`uv run python -m scripts.evaluate_ai` verifies 17 deterministic fallback extraction fixtures. It does not call the generative parser. `make test-mutations` requires each selected mutation to produce an ordinary assertion failure; setup/collection errors are not accepted. `tests.operations` checks eight guarded dependency/replay/API-IP scenarios only against taskbot-qa. Local artifacts live under ignored reports/; CI has its own artifacts.

The two real speech cases use a public English sample and synthetic English field dictation. They test actual CPU speech recognition, all structured fields, Yerevan/UTC conversion, task uniqueness, SSE and confirmation. Telegram HTTP alone is mocked. No measured Armenian WER or broad live paid-model comprehension rate is claimed. README's ten longer examples are manual acceptance scenarios with expected semantics.
