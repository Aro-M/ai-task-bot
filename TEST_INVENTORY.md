## Supplemental checks

`make test-mutations` alters temporary source copies to check ownership, OTP expiry, JWT signature, Telegram identity, empty speech, CSRF, event privacy and completion timestamps. A genuine test failure is required, not a collection error. `tests.operations` exercises eight guarded pause/replacement/redelivery scenarios on `taskbot-qa`; scenario outcomes are in local `reports/qa-resilience.json`. No main application volumes are reset.

## Optional real local speech cases (excluded from the ordinary count)

`tests/e2e/test_local_voice.py::test_local_speech_voice_queue_task_sse_and_confirmation` — real-speech service E2E/security. Two parameterized cases run actual base model inference: public speech and synthetic English field dictation. Checks recognized words/all four fields, unique task/event, zero provider estimate, owner SSE and metadata confirmation; only Telegram is mocked. Run **`make test-local-ai`**, which supplies its isolated model service/database/Redis. Ordinary CI intentionally skips it to avoid model downloads. The regular fixture database guards remain active.
