# AI reliability design

Only the background worker sends audio to OpenAI Whisper (`whisper-1`, auto language by default). The application accepts English/Armenian results and rejects other languages with text fallback. Whisper timeout defaults to 45s; provider budget is at most WHISPER_MAX_RETRIES=3 total HTTP attempts, configurable 1–5 (the name is historical: it means attempts). Backoff defaults to 2s then 4s with 0–0.25s jitter, capped at 30s. The whole job has a 60s asyncio deadline, overriding the per-request retry budget. Telegram downloads have three transient attempts, separate 15s HTTP timeout and partial-file cleanup. Tools have 15s deadlines. Circuit opens at five transient failures for 30s with a 60s failure counter window; global AI attempts are rate limited.

Provider retry exhaustion enters DEAD_LETTER and notifies with a clear text alternative. Invalid audio/output fails safely. Job timeout remains TIMED_OUT for compatibility and can be manually retried within the shared three-retry/24h budget. Infrastructure failure uses Celery base-2 exponential/full jitter up to 60s; retries are durable and shared with recovery/manual requests. Recovery covers stale QUEUED/RETRYING/PROCESSING, checks TTL and locks, and preserves one task per source key. Terminal failed storage is purged after seven days by the dispatcher.

Secure TemporaryDirectory cleanup runs on success/failure/cancellation; a hard process kill leaves RAM storage only until container replacement. No separate raw transcript or audio is stored. Canonical audio is mono 16kHz WAV. Normalization preserves meaning and original words, with long text kept in description. Explicit date/priority extraction is deterministic and optional; ambiguous times (including Armenian “6” without AM/PM) are not invented. Relative dates use UTC. A generative structuring model adds no necessary reliability benefit and is omitted; model output is never executed.

Starting with `Title` or `Վերնագիր` opts into explicit English/Armenian fields: title, description, deadline/due date and priority. Labels are reserved delimiters in that mode. Empty/repeated fields, invalid dates, ambiguous explicit times, and priorities outside low/medium/high fail before task creation. Description text is not scanned for incidental date/priority words. Named English dates require a year; relative dates and all bot times still use UTC. Speech renderings such as `630pm`, `6.30pm`, `six thirty PM`, and the observed label homophone `do date` are normalized deterministically. Unstructured input retains its previous preservation/inference behavior. New tasks start PENDING; status is managed in the dashboard. Success replies show the extracted metadata and up to 1,000 description characters; full descriptions remain in the task. Safe parser errors are sent as actionable fallback text.

Job latency, audio duration, successful estimates and retained outcomes are queryable by owners; operator metrics report aggregates plus daily provider attempts/HTTP failures. Cost uses configured price (default $0.006/minute) and is not a billing reconciliation. Provider retries may incur additional charges. Synthetic tests/17 extraction examples do not measure speech WER or real Armenian accuracy. Private staging needs consented labeled recordings, confidence checks and real-provider fault/cost validation before launch.

## Free development inference

`make up-local-ai` selects a private whisper.cpp service using the existing HTTP response validation. The multilingual `base` model replaces tiny; its 141-MiB download is pinned and checksum verified. The service retains its 2-CPU/1-GiB limit; an observed synthetic sample used roughly 240 MiB and took 10–14 seconds, which is not a general capacity or accuracy guarantee. No OpenAI account/key is needed and the overlay forces a local-only placeholder key plus WHISPER_COST_PER_MINUTE=0. Production's official-host restriction is retained. `make test-local-ai` uses a public 11-second English recording and a synthetic English field-dictation recording with real model inference; only Telegram is mocked. Recognition is subject to the same 45-second request/60-second whole-job defaults; long audio and emulation can reach the deadline. Initial image/model download requires internet; inference makes no external AI request. Existing model volumes are retained; old tiny files are harmless cache and are not deleted by upgrades.

`tests/fixtures/voice-fields.wav` contains no user recording: it was synthesized locally with macOS Samantha at 140 words/minute (mono PCM16, 16 kHz). Reference: “Title. Call Anna. Description. Discuss the report. Due date. Tomorrow at six P M. Priority. High.” Its real-inference test verifies every stored field, unique task/event, owner SSE, zero provider estimate and final confirmation. The historical public-speech sample remains a separate smoke case. Neither establishes accent/noise robustness.

Live Telegram follow-up also rejects standalone `[ Inaudible ]`, unintelligible and no-speech markers before task creation. Whitespace/case/brackets are normalized for the refusal comparison only; meaningful sentences containing those words remain unchanged. This closes a reproduced local-model output failure and does not establish general speech accuracy.

## Bilingual field dictation

The shared parser accepts Armenian field labels (including definite forms and «է»), Armenian punctuation, high/medium/low priority words in both languages, and mixed-language fields. Explicit Armenian times support 24-hour digits or common number words, for example «ժամը տասնութն անց երեսուն». Today/tomorrow use the existing UTC clock; bare ambiguous «վեց» is rejected in structured mode. English behavior is retained. Armenian month names, colloquial time phrases and timezone inference are not implemented. No translation or new model service is introduced.

Speech language remains automatic; the multilingual base model and provider settings are unchanged. A recognized Armenian result gets Armenian success/metadata labels. /help includes both examples. Unit tests exercise full Armenian and mixed dictation through both ingestion paths, duplicate/error safety and metadata isolation; their Armenian transcription edge is mocked. The actual-model English cases remain regression smoke tests. No labeled Armenian recording was available to establish Armenian ASR accuracy. This change adds no dashboard language selector.
